Sound Chunk Marker — клиентский Fabric-мод для Minecraft 1.21.8

Что делает:
- отмечает красной рамкой вертикальную колонну чанка, в котором был воспроизведён подходящий звук;
- учитывает звуки entity.player.attack.*;
- учитывает звуки entity.<mob>.*, кроме entity.bat.*, entity.zombie.* и entity.zombified_piglin.*;
- метка исчезает через 12 секунд после последнего подходящего звука в чанке.

Установка:
1. Установи Fabric Loader для Minecraft 1.21.8.
2. Установи Fabric API для Minecraft 1.21.8.
3. Скачай собранный sound-chunk-marker-1.0.0.jar из GitHub Actions Artifacts.
4. Положи JAR в папку .minecraft/mods.

Важно:
- Это клиентский мод: на сервер FunTime ничего устанавливать не нужно.
- Он видит только звуки, которые сервер действительно отправляет твоему клиенту и которые Minecraft воспроизводит.
- Minecraft не всегда проигрывает отдельный звук на обычный взмах мечом; мод ловит доступные entity.player.attack.*.
- Фильтр entity.* широкий: некоторые звуки сущностей, которые не являются мобами, тоже могут отмечаться.
- Зомби, зомбированные пиглины и летучие мыши исключены по ID звука.
